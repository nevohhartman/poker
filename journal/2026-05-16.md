This is huge part of the project and very complicated:
I first started by implementing insertion sort (with the help of claude for explenations), allowing me to first sort 7 cards ( centre + player draw)

Initially I tried to run multiple checks at once (like flush straight flush and flush), but keeping track of it proves difficult and the code will be far easier to follow if I seperate the checks.

The code works as follows:

First pass through the sorted cards and fill a frequency array for ranks and suits

Flush takes the suit info:
If one of the suits has frequency 5 -> go through the first 3 cards and the highest one of the suit is ur high (hearts ace high for example). Only need to go first 3 as that has to include the flush (pigeonhole). I also realised you only the highest card, as there can only be one suit for a flush per round of poker (as in one player cant have clubs and the other hearts), and thus for ties you only need to check the highest card.

Straight flush runs its own pass as it does a check for suit and rank at the same time, keeping track of the highest card of the current run and outputitng it at the end.

Straight was the same as straight flush just using only the frequency table as suits don't matter.
